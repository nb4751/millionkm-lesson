# 개인정보와 운영 범위

## 기본 공통 주소 모드

이 프로젝트는 사용자가 요청한 **로그인 없이 이름을 선택하는 공통 주소** 방식이 기본입니다. `APP_OPEN_PORTAL=1`에서 주소를 아는 누구나 모든 활성 선수 이름·활동·분석을 보고, 선수 이름을 선택해 업로드하고 비교·엑셀 출력을 할 수 있습니다. 이름 선택은 본인 확인이 아니므로 다른 선수 이름으로 업로드하는 것도 기술적으로 가능합니다.

이 모드에 선수별 정보 격리나 업로더 신원 인증이 있다고 안내하면 안 됩니다. 기록을 함께 보는 목적에 맞는 운영인지 확인하고, 선수·필요한 경우 보호자에게 공유 범위와 엑셀 사본 생성 가능성을 알리세요. 이 주소를 무관한 공개 게시판에 올리지 않는 것이 좋습니다.

선수 수정·삭제·비활성화·FTP 변경·전체 백업 같은 관리 기능은 공유 방문자에게 허용하지 않습니다. 로그인 없는 관리 권한은 코치 PC의 로컬 전용 서버에 한정합니다. **관리용 8000 포트를 터널·인터넷에 연결하지 마세요.** PC를 함께 사용하는 사람은 로컬 관리 화면에 접근할 수 있으므로 Windows 계정·잠금·디스크 권한을 유지합니다.

## 선택적 비공개 모드

선수별 접근을 제한하려면 `APP_OPEN_PORTAL=0`으로 설정하고 선수 개인 링크를 사용합니다. 링크 자체가 접근권한이므로 가진 사람은 해당 선수 기록에 별도 비밀번호 없이 접근할 수 있습니다. 기본 유효기간은 90일이며 재발급 시 이전 링크를 무효화합니다. 유출이 의심되면 코치가 폐기/재발급합니다.

비공개 모드를 사용할 때는 실제 휴대폰에서 타 선수 ID 접근·엑셀·원본 다운로드 차단을 확인하세요. 공통 모드와 비공개 모드는 데이터 공유 범위가 다릅니다. 원래 계정·초대 기반 인증 기능이 존재하더라도 기본 공통 주소 방문자가 가입을 해야 하는 것은 아닙니다.

## 최소 수집과 동의

심박·체중·운동 기록은 사적인 정보입니다. 실제 공개 전 대한민국 개인정보보호법과 미성년자 동의 의무, 개인정보 처리방침을 운영 상황에 맞게 검토하세요. 구현된 권한·기록 기능만으로 모든 법적 요건을 충족했다고 단정하지 않습니다.

관리 목적에 필요한 최소 정보만 받습니다. 주민등록번호, 집 주소, Garmin 계정 비밀번호는 수집하지 않습니다. 선수·보호자에게 수집 항목, 목적, 공유 대상과 방식, 보관기간, 외부 호스팅 여부, 열람·삭제 요청 방법을 고지하고 증빙을 보관합니다. 화면의 체크만으로 보호자 신원 확인을 대신하지 않습니다.

원본 FIT에는 GPS 경로 등으로 거주지·학교를 추정할 수 있는 위치가 포함될 수 있습니다. 공통 포털에서는 원본 파일 다운로드를 차단합니다. 코치 또는 비공개 모드의 해당 선수만 원본을 내려받을 수 있으며, GPS 공개 지도는 제공하지 않습니다. 원본을 포함하는 전체 백업과 코치 PC의 파일 보관도 보호해야 합니다.

## 보관과 삭제

- 운영자가 보관기간과 처리 담당자를 정합니다. 자동 법정 보관기간 판단·무인 일괄 파기는 제공하지 않습니다.
- 삭제 요청은 본인 확인과 보존 사유 검토 후 코치가 처리합니다. 요청 접수와 실제 삭제는 구분합니다.
- 오래된 백업·엑셀 사본에도 삭제 대상이 남을 수 있습니다. 백업 보관기간과 복구 시 삭제 재반영 절차를 둡니다.
- 감사기록은 확인에 도움을 주지만 공통 모드에서는 업로더를 실명 인증한 기록이 아닙니다. 변조 방지 전용 외부 로그 시스템도 아닙니다.
- 백업·엑셀은 별도의 개인정보 사본입니다. 암호화된 보관소와 접근제한을 사용하고 무분별하게 재전송하지 마세요.

## 파일·서버와 운영 항목

허용 형식·용량 제한·서버 측 파싱·무작위 저장 이름·중복 확인은 안티바이러스나 모든 악성 파일 탐지를 대신하지 않습니다. 업로드를 공개 static 경로에 두지 않고 OS·패키지 보안 업데이트, HTTPS, 디스크 용량·백업 실패 점검을 유지합니다.

공개 전 실제 공유 범위, 코치 기능 차단, 비공개 모드를 선택한 경우의 선수별 접근 차단, 백업 복구를 확인합니다. 책임자·연락 방법, 동의 절차, 각 데이터의 보관기간, 삭제 요청 기한, 서비스 제공 시간, 장애 대응, 외부 서비스 비용과 데이터 처리 조건을 정하세요.
