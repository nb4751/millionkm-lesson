# 첫 버전 구현·검증 결과

검증일: 2026-10-28 (한국 시간). 제품명: 권순영 코치 개인레슨 데이터 관리 / LESSON LAB.

## 실제 사용할 흐름

기본은 로그인 없는 공통 공간입니다. 코치 PC에서 선수 이름을 등록한 뒤 이름별 보관함에 Garmin FIT·CSV 파일을 넣습니다. 코치가 여러 선수의 파일을 직접 올려도 됩니다. 외부 공유 서버를 별도로 설정하면 선수들도 공통 HTTPS 주소 하나에서 이름을 찾아 업로드·열람합니다. 이름 선택은 본인 인증이 아니며, 공통 모드에서는 다른 선수 기록도 볼 수 있습니다. 관리용 로컬 서버와 외부 공유 서버의 포트를 분리합니다.

## 구현한 기능

- 한국어 PC·모바일 대시보드, 선수 등록·수정·비활성화·삭제, 동명이인 고유 ID.
- 이름을 선택하는 FIT·CSV 업로드, 알려진 열 자동 인식과 사용자 열 선택, UTF-8/CP949, 한국 시간 표시.
- Garmin 공식 FIT SDK 사용, CRC 검증, record/session/lap·타이머 정지 해석, 원본·표준화 기록·출처 보관.
- 파일/활동 중복 방지, 파일 크기·기록 수·활동 수·원본 저장공간 제한, 공통 모드 업로드 빈도 제한.
- 파워·심박·케이던스 그래프, 평균/최대, NP·VI·IF·TSS·kJ·W/kg, 시간가중 파워커브, 파워존.
- FTP 출처·적용일 이력. 업로드 시 활동일 이전의 최신 기준 FTP를 저장하며 과거 기록을 자동 변경하지 않음.
- 날짜별 기록과 장기 훈련부하 추정 추세, 수동 인터벌 목표·실행 비교, 센터/개인훈련 구분·RPE 입력.
- 동일 기간 선수 비교, 8개 시트 Excel 보고서, 주간 집계와 비교 차트.
- 가상 선수 3명·활동 18개, 반복 실행 가능한 샘플 생성 명령과 업로드용 CSV.
- 로컬 코치 전용 삭제·전체 백업, SQLite 실제 복원 검증, 체크섬 백업 검사 도구, 감사로그·데이터 요청.
- 공통 화면 원본 다운로드 차단(GPS 보호), 관리용 기능 접근 차단, 선택적 선수별 비공개 링크 모드.
- 원래의 계정·일회용 초대 기능도 선택적으로 남아 있으나 기본 사용에는 로그인·비밀번호가 필요 없음.
- Miniconda Windows 설치/실행 스크립트, 별도 HTTPS 공유 서버 스크립트, Docker 배포 구성과 한국어 문서.

Python 3.12.14 / Django 5.2.18 / Garmin FIT SDK 21.218.0 / SQLite / Linux 환경.

## 아직 제공하지 않거나 실제 시험하지 않은 부분

- Garmin 계정 자동 동기화, TrainingPeaks/WKO 연동 및 해당 제품과의 수치 일치 보장.
- 모든 Garmin 장비 실파일 검증, 고급 사이클링 다이나믹스 전체 표시, 고도·속도·경사/심박존 상세 분석, GPS 지도.
- 원본 일괄 재처리 UI, 과거 FTP 기준 일괄 재계산 선택, 훈련 처방·자동 인터벌 탐지, 주간 달력 UI, 자동 보관기간 파기.
- PostgreSQL·객체 저장소·다중 코치/다중 서버, 대용량 비동기 작업·안티바이러스 연동.
- 실제 Windows PC의 Miniconda/배치 실행, Docker build/run, 실제 스마트폰 기기·실제 HTTPS 터널/도메인 배포는 **미검증**입니다. 제공 구성만으로 배포가 완료된 것은 아닙니다.

## 운영 전에 필요한 설정

코치 PC를 켜 두는 것 외에 서버 프로그램 실행·절전 해제·인터넷 연결이 필요합니다. 외부 접속에는 실제 HTTPS 주소와 별도 공유 서버가 필요하며, 관리용 8000 포트를 외부에 연결하지 않습니다. 운영 비밀키·허용 호스트·CSRF 주소·신뢰 프록시·공개 주소를 설정하세요. 공통 주소에서 다른 사람의 이름으로 파일을 올릴 수 있으므로 공유 범위/동의를 확인하고 원본·Excel·백업을 관리하세요. 백업과 개인정보 보관·삭제 정책은 운영자가 정해야 합니다.

현재 클라우드 인스턴스 설치·검증과 재사용 설치/시작 지침 초안 저장을 마쳤습니다. 환경 설정 검토·저장·게시는 별도이며, Windows PC 설치와 외부 호스팅 배포를 수행했다는 의미는 아닙니다.
